# Serfiliana B2B

Scaffold inicial para una plataforma B2B lista para desplegar en Vercel.

Características incluidas en este commit inicial:
- Next.js (app router) + TypeScript
- Tailwind CSS
- Prisma (esquema base)
- Stripe (helpers de servidor)
- Estructura básica de carpetas para Admin y Cliente

Despliegue en Vercel:
1. Conecta este repo a Vercel.
2. Añade las variables de entorno listadas en `.env.example`.
3. Ejecuta `vercel --prod` o configura despliegue automático.
